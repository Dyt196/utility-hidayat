# Hidayat Utility

Free, fast online calculators and converters at https://utility.hidayat.my. Fully static, no backend, no database, no tracking; every calculation runs in the browser. Currently: age, percentage, unit, BMI and date calculators, in English and Bahasa Melayu.

## Stack

Nuxt 4 · Vue 3 · TypeScript · Tailwind CSS v4 · `@nuxtjs/i18n` · `@nuxtjs/sitemap` · `@nuxtjs/robots` · Nitro static prerendering.

## Development

```bash
npm install
cp .env.example .env   # optional
npm run dev            # http://localhost:3000
```

| Script | What it does |
| --- | --- |
| `npm run dev` | Dev server |
| `npm run typecheck` | `vue-tsc` type check |
| `npm test` | Calculation self-checks (`tests/calc.test.ts`, Node's built-in runner) |
| `npm run build` | Production build |
| `npm run generate` | Prerender every route to `.output/public` |
| `npm run preview` | Serve the build locally |

Environment variables (see `.env.example`): `NUXT_PUBLIC_SITE_URL` (canonicals, sitemap, Open Graph) and `NUXT_PUBLIC_CONTACT_EMAIL` (shown on `/contact`).

## Structure

```
app/
  components/        shared UI (ToolLayout, InputField, ResultCard, ...)
  components/tools/  one component per calculator (UI only)
  content/           all copy per language: en.ts is the source of truth, ms.ts must match its type
  composables/       useContent (active-language copy), usePageSeo
  utils/             pure calculation code (no Vue) + tools.ts registry
  pages/             routes; tool pages are 3 lines wrapping ToolLayout
tests/calc.test.ts   checks for the calculation code
```

## Add a new utility

1. Put the logic in `app/utils/<name>.ts` (pure functions) and add cases to `tests/calc.test.ts`.
2. Create `app/components/tools/<Name>.vue` using `InputField`, `SelectInput` and `ResultCard`.
3. Add `app/pages/tools/<slug>.vue`:
   ```vue
   <template><ToolLayout slug="<slug>"><Tools<Name> /></ToolLayout></template>
   ```
4. Add `{ slug, category, related }` to `app/utils/tools.ts`.
5. Add `tools['<slug>']` to `app/content/en.ts` and `ms.ts` (name, short, metaTitle, metaDescription, h1, intro, ui, how, examples, faq). TypeScript fails the check if `ms.ts` is missing keys.

The homepage, `/tools`, related links, sitemap and prerendering pick it up automatically.

## SEO

- `ToolLayout` sets title, description and Open Graph per tool, plus `WebApplication` and `BreadcrumbList` JSON-LD. Other pages call `usePageSeo()`.
- Canonical, `hreflang`, `og:url` and `og:locale` come from `useLocaleHead()` in `app.vue`. Site-wide `og:image` and the favicon links are in `nuxt.config.ts`.
- `sitemap.xml` and `robots.txt` are generated by the modules from the prerendered routes.
- To add metadata to a new page, call `usePageSeo({ title, description, jsonLd? })`.

## Languages

English (default, no prefix) and Bahasa Melayu (`/ms/...`). Add a language: create `app/content/<code>.ts`, register it in `app/composables/useContent.ts` and `i18n.locales` in `nuxt.config.ts`.

## Build and deploy

```bash
npm run generate     # outputs .output/public
```

Upload `.output/public` to any static host or CDN (Cloudflare Pages, Netlify, Vercel, S3 + CloudFront). Set `NUXT_PUBLIC_SITE_URL` at build time. Unknown URLs should serve `404.html`.

## Later: ads and analytics

- Analytics: add the script/SDK in `app/plugins/analytics.client.ts`.
- Ads: `ToolLayout` has an `after-tool` slot and independent `<section>`s; insert an ad component between them. Update the privacy policy (`app/content/*.ts`) and add consent handling first.
